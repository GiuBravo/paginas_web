# Internacionalização (i18n)

## Idiomas suportados

| Código | Arquivo | Padrão |
|--------|---------|--------|
| `pt-BR` | `src/locales/pt-BR.json` | Sim (se navegador não for inglês) |
| `en` | `src/locales/en.json` | Se `navigator.language` começa com `en` |

Persistência: `localStorage` chave `idioma_armazenado`.

## Uso no HTML

```html
<span data-i18n="app.title">Wiki Lust Goddess</span>
<input data-i18n="gifts.search" placeholder="…" />
<button data-i18n-aria="btn.stepUp" aria-label="…">
```

O texto dentro da tag é **fallback** até `applyTranslations()` rodar.

Chaves especiais:

- `data-i18n-html` — permite HTML no valor traduzido.
- `data-i18n-aria` — preenche `aria-label`.

## Uso no JavaScript

```js
import { t, formatNumber, setLocale, applyTranslations } from './i18n.js';

t('field.levelRangeDynamic', { max: 31 }); // "1–31"
formatNumber(2270); // "2.270" (pt) ou "2,270" (en)
```

Callback global após troca de idioma:

```js
setOnLocaleChange(() => { /* re-render tabelas, selects, cálculo */ });
```

## Adicionar um idioma

1. Copie `src/locales/pt-BR.json` para `src/locales/xx.json` com **todas** as chaves.
2. Em `src/i18n.js`:
   - importe o JSON;
   - adicione em `LOCALES`;
   - inclua o código em `SUPPORTED`.
3. Em `index.html`, adicione botão no `.lang-switcher` com `data-lang="xx"` e `id` único.
4. Em `main.js`, registre o listener em `atualizarLangButtons()` (espelhe `lang_pt` / `lang_en`).
5. Traduza `meta.title` no JSON (usado em `document.title`).

## Chaves geradas dinamicamente

Alguns selects usam `data-i18n` nas `<option>` (raridade). Reinícios usam `preencher_opcoes_reinicio()` com chave `restart.option`.

Mensagens de erro de cálculo: `error.INVALID_RANGE`, `error.CURRENT_AFTER_DESIRED`, etc. (ver JSON completo).

## Formatação numérica

`formatNumber` usa `pt-BR` ou `en-US` conforme o locale ativo. Não confunda com parsing: `giftsCalc.sanitizarPontos` remove não-dígitos antes de validar.
