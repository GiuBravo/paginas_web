# Internationalization (i18n)

## Supported languages

| Code | File | Default |
|------|------|---------|
| `pt-BR` | `src/locales/pt-BR.json` | Yes (unless browser is English) |
| `en` | `src/locales/en.json` | If `navigator.language` starts with `en` |

Persistence: `localStorage` key `idioma_armazenado`.

## HTML usage

```html
<span data-i18n="app.title">Wiki Lust Goddess</span>
<input data-i18n="gifts.search" placeholder="…" />
<button data-i18n-aria="btn.stepUp" aria-label="…">
```

Text inside the tag is a **fallback** until `applyTranslations()` runs.

Special attributes:

- `data-i18n-html` — allows HTML in the translated value.
- `data-i18n-aria` — sets `aria-label`.

## JavaScript usage

```js
import { t, formatNumber, setLocale, applyTranslations } from './i18n.js';

t('field.levelRangeDynamic', { max: 31 }); // "1–31"
formatNumber(2270); // "2.270" (pt) or "2,270" (en)
```

Global callback after locale change:

```js
setOnLocaleChange(() => { /* re-render tables, selects, calculation */ });
```

## Adding a language

1. Copy `src/locales/pt-BR.json` to `src/locales/xx.json` with **all** keys.
2. In `src/i18n.js`:
   - import the JSON;
   - add to `LOCALES`;
   - include the code in `SUPPORTED`.
3. In `index.html`, add a button in `.lang-switcher` with `data-lang="xx"` and a unique `id`.
4. In `main.js`, register the listener in `atualizarLangButtons()` (mirror `lang_pt` / `lang_en`).
5. Translate `meta.title` in the JSON (used for `document.title`).

## Dynamic keys

Some selects use `data-i18n` on `<option>` (rarity). Restarts use `preencher_opcoes_reinicio()` with key `restart.option`.

Calculation errors: `error.INVALID_RANGE`, `error.CURRENT_AFTER_DESIRED`, etc. (see full JSON).

## Number formatting

`formatNumber` uses `pt-BR` or `en-US` per active locale. Do not confuse with parsing: `giftsCalc.sanitizarPontos` strips non-digits before validation.

## Manual test

1. Toggle PT ↔ EN in the header.
2. Check reference tables, restart guide, and Gifts tab.
3. Copy result — text should match current language.
4. Reload — locale should persist.
